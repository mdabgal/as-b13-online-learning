
#  SkillSphere - Online Learning Platform

## Live Site
https://as-b13-online-learning.vercel.app

##  Project Purpose
SkillSphere is a modern online learning platform where users can explore, search, and enroll in skill-based courses like Web Development, Design, and Marketing.

---

##  Features

-  User Authentication (Login/Register)
-  Google Login (OAuth)
-  Browse All Courses
-  Search Courses by Title
-  Course Details Page (Protected)
-  User Profile Page
-  Update Profile (Name & Image)
-  Framer Motion Animations
-  Fully Responsive Design
-  404 Not Found Page

---

##  Tech Stack

- Next.js (App Router)
- Tailwind CSS
- DaisyUI
- BetterAuth
- Framer Motion
- React Icons
